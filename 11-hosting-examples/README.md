# Hosting examples

Every authored folder and file in this distribution is numbered. GitHub automatically discovers a README and workflows only in its recognized reserved locations; these examples do not activate that behavior. The public entry page is [00-INDEX.md](../00-INDEX.md), and [01-ci-workflow-example.yml](01-ci-workflow-example.yml) records the complete validation commands.

A maintainer who later chooses to activate hosting automation must configure the host's reserved workflow location. That is a separate hosting choice because it introduces a system-required path outside the fully numbered course layout. Until configured and executed, no hosted CI success is claimed. Run the numbered local checker to reproduce the verification.
