# Release evidence checklist

## Exact inputs
Source revision, artifact digest, builder identity and target environment.

## Verification
Test results, dependency policy, provenance claims, authorization decision and reviewer. Record actual evidence locations rather than unchecked claims.

## Rollout
Stages, minimum traffic/sample, observation duration, good-event definition and abort threshold.

## Recovery
Rollback candidate, data compatibility, forward-fix option and owner.

## Completion
Observed user outcome, telemetry coverage, operation ID and follow-up work.
